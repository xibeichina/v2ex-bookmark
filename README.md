# 🔖 V2EX Bookmark

> 一键将 V2EX 账号里的“收藏夹”全量同步到本地浏览器书签。防封号、防失联，你的数据归你自己。

V2EX 账号突然被 Ban？几十页精心收藏的技术贴瞬间灰飞烟灭？
写这个小插件就是为了解决这个痛点：**把 V2EX 上的云端收藏，变成绝对安全的本地浏览器书签。**

---

## ✨ 核心特性

- 🚫 **无 Token 依赖**：不需要折腾 Cookie，不需要填 API Token。插件利用浏览器原生机制，只要你当前网页登录了 V2EX，点开即用。
- ⚡️ **智能增量同步**：每次备份前会自动比对本地已存在的书签，**只同步新增内容**，不会每次都搞出一堆重复的书签和垃圾文件夹。
- 🛡️ **防 WAF 拦截**：内置请求延迟与并发控制。哪怕你有几十页的收藏，也会像正常人类一样平滑翻页抓取，绝不触发站点的反爬限制。
- 🔒 **绝对隐私安全**：网络请求仅发生在 `你的浏览器 <-> V2EX` 之间，数据直接写入本地书签，代码开源透明，**没有任何第三方服务器中转**。

## 🚀 安装指南

由于本项目主打极简实用，未上架 Chrome Web Store（省了 5 刀注册费 🐶），请直接使用浏览器的**开发者模式**进行安装：

1. 在本仓库的 [Releases](../../releases) 页面下载最新版本的 `.zip` 压缩包，并解压到一个固定的文件夹。
2. 打开浏览器，地址栏输入 `chrome://extensions/` 并回车。
3. 开启页面右上角的 **开发者模式** 开关。
4. 点击左上角的 **加载已解压的扩展程序**。
5. 选择你刚才解压的项目文件夹，安装完成！

*(建议在浏览器右上角的拼图 🧩 菜单里，把插件固定到工具栏，方便随时调用)*

## 🕹️ 如何使用

1. 确保你在当前浏览器中已经登录了 V2EX。
2. 点击右上角的 `V2EX Bookmark` 插件图标。
3. 点击 **「开始同步到书签」**。
4. 喝口水，看着状态栏的进度走完（为了防止被封 IP，翻页抓取设置了安全延迟，页数较多时请耐心等待）。
5. 打开浏览器的书签管理器，找到名为 **`V2EX 备份收藏`** 的文件夹，你的心血都在这里了。

## 🛠️ 技术栈与开发说明

本项目采用纯原生 **Vanilla JS + HTML + CSS** 以及最新的 **Manifest V3** 规范开发。
没有引入任何复杂的打包工具和前端框架，主打一个轻量、透明、即拿即用。
